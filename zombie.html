Acerca del Proyecto

Este fue mi primer videojuego desarrollado en Unity. Es un plataformas 2D de acción y aventura en el que el jugador controla a un aldeano que lucha contra zombies. A medida que avanza por los niveles, debe recolectar monedas para progresar, mientras busca derrotar al causante del brote y salvar su aldea.

El videojuego cuenta con 3 niveles y 1 Boss Fight, cada uno con una ambientación y diseño de escenario distinto, buscando transmitir diferentes sensaciones visuales y variaciones en la exploración a lo largo de la aventura. A medida que el jugador avanza, la dificultad aumenta progresivamente con mayores desafíos. Además, el jugador cuenta con una sola vida durante toda la partida, por lo que el jugador debe aprovechar cuidadosamente sus recursos y movimientos para sobrevivir.

Sistema de Player

  • Implementé el sistema de control del jugador, incluyendo movimiento horizontal , salto y dos tipos de ataque :

  • Ataque a distancia→ Disparar proyectiles (bayas).

  • Ataque Meele→ Defenderte cuarpo a cuerpo (trinche).

Sistema de Enemigos

  • Implementación de patrullaje de enemigos.

  • Comportamientos diferenciados por tipo de enemigo :

  • Zombie Lady→ Enemigo que dispara proyectiles (balas de sangre).

  • Zombie Grandulon→ Mayor velocidad de patrullaje.

Sistema de items

  • Implementé un sistema de recolección de ítems con distintas funciones :

  • Municion → Sirven para disparar.

  • Monedas → Necesarias para avanzar entre niveles.

Sistema de Player - Ataques

Ataque a distancia

Ataque que genera proyectiles. Al colisionar con un enemigo, el proyectil le aplica daño. Este ataque permite al jugador defenderse a mayor distancia.

Ataque Meele

Se implementó un sistema de combate con trinche que reutiliza la lógica de codigo del ataque a distancia. El arma se instancia durante un tiempo breve, generando la sensación de un golpe directo contra los enemigos cuerpo a cuerpo.

        using System.Collections;
        using System.Collections.Generic;
        using UnityEngine;
        using UnityEngine.SceneManagement; 

        public class Villager : MonoBehaviour
        {
            public int ammo;
            public GameObject bulletPrefab;
            public GameObject bulletPrefab2;
            public float direction;
            public BulletManager bulletManager;
            public AudioSource audioSource;
            public AudioClip soundShootPlayer;
            public AudioClip AmmoClip;


            void Update()
            {
                Shoot();
                Move();
            }

            void Move()
            {
                //Movimiento y direccion
                float horizontal = Input.GetAxis("Horizontal");
                if (horizontal > 0)
                {
                   direction = 1;
                }
                else if (horizontal < 0)
                {
                   direction = -1;
                }

                Vector3 scale = transform.localScale;
                if (direction < 0)
                {
                   scale.x = -2;
                }
                else
                {
                   scale.x = 2;
                }
                transform.localScale = scale;

                rb2d.velocity = new Vector2(horizontal * speed, rb2d.velocity.y);
                animator.SetFloat("speed", rb2d.velocity.x);

            }

            void Shoot()
            {
                //Ataque a distancia
                //Apreta la tecla "X" para poder disparar
                if (Input.GetKeyDown(KeyCode.X) && ammo >= 1 && Time.timeScale > 0)
                {
                    GameObject obj = Instantiate(bulletPrefab);
                    obj.transform.position = transform.position;
                    Vector2 dir = obj.GetComponent().direction;
                    dir.x = direction;
                    obj.GetComponent().direction = dir;   
                    ammo--;
                    bulletManager.SetBullet(ammo);
                    audioSource.PlayOneShot(soundShootPlayer);
                } 
               
            }

            private void OnTriggerEnter2D(Collider2D collision)
            {
                //Recoges la municion de tus balas para poder disparar
                if (collision.gameObject.CompareTag("Ammo"))
                {
                    ammo++;
                    bulletManager.SetBullet(ammo);
                    Destroy(collision.gameObject);
                    audioSource.PlayOneShot(AmmoClip);
                }

            }

        }




       
        using System.Collections;
        using System.Collections.Generic;
        using UnityEngine;

        public class Bullet : MonoBehaviour
        {
            public Rigidbody2D rb2d;
            public Vector2 direction;
            public int speed;
            public float timer;
            public float MaxTimer=1f;

            void Start()
            {
                rb2d = GetComponent<Rigidbody2D>();
            }

            void Update()
            {
                Move();
            }

            void Move()
            {
                //Movimiento y vida de tiempo de la bala
                rb2d.velocity = direction * speed;
                timer += Time.deltaTime;
                if (timer >= MaxTimer)
                {
                    Destroy(gameObject);
                    timer = 0;
                }
            }
        }

Lo que aprendi

Este proyecto representó mi primera experiencia desarrollando un videojuego en Unity, por lo que aprendí muchos conceptos relacionados con la programación y el uso del motor de Unity. Al inicio pensé que sería una tarea complicada, ya que trabajábamos en un equipo de 4 integrantes donde cada uno tenía un rol más definido. En mi caso, al comienzo no tenía una especialidad marcada, pero debido a la falta de programadores en el grupo asumí la responsabilidad de encargarme de la programación.

Con el paso del desarrollo, fui adaptándome cada vez más a ese rol y descubrí que la programación era un área que realmente me interesaba. A medida que avanzaba el proyecto, comprendí mejor como resolver problemas y aplicar lógica de programación dentro de Unity. Gracias a esta experiencia, mejoré mis habilidades técnicas y gané más confianza trabajando en proyectos de desarrollo de videojuegos.
