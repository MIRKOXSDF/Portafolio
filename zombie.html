Zombie in the Village

Acerca del Proyecto

"Zombie in the Village" fue el primer proyecto que desarrollé durante el ciclo de la Universidad, donde participé como programador. Se realizó en un entorno colaborativo, aplicando los fundamentos del desarrollo de videojuegos a partir de una idea base que fue evolucionando progresivamente hasta convertirse en un producto completamente funcional.

Es un videojuego de acción y aventura en 2D tipo side scroller. El jugador controla a un aldeano que debe atravesar distintos portales mientras evita y combate a los zombies usando su trinche y su resortera, que dispara bayas. Durante el recorrido, también debe recolectar monedas para poder avanzar al siguiente nivel.

Ataque del jugador

Ataque meele
Ataque Disparo

Se implementaron dos tipos de ataque: ataque meele utilizando un trinche, y ataque a distancia mediante disparo de balas. Ambos comparten una base lógica similar en el código, diferenciándose principalmente en el comportamiento del proyectil. En el caso del ataque melee, se instancia un proyectil con un tiempo de vida muy corto y un alcance limitado, lo que permite simular un impacto cuerpo a cuerpo. Por otro lado, el ataque a distancia genera un proyectil convencional que al detectar con el enemigo le genera daño.

                //Ataque a distancia
                if (Input.GetKeyDown(KeyCode.X) && ammo >= 1 && Time.timeScale > 0)
                {
                    GameObject obj = Instantiate(bulletPrefab);
                    obj.transform.position = transform.position;
                    Vector2 dir = obj.GetComponent().direction;
                    dir.x = direction;
                    obj.GetComponent().direction = d;   
                    ammo--;
                    bulletManager.SetBullet(ammo);
                    audioSource.PlayOneShot(soundShootPlayer);
                } 
                //Ataque a Meele
                if (Input.GetKeyDown(KeyCode.Z) && Time.timeScale > 0)
                {
                    GameObject obj = Instantiate(bulletPrefab2);
                    obj.transform.position = transform.position;
                    Vector2 dir = obj.GetComponent().direction;
                    dir.x = direction;
                    obj.GetComponent().direction = d;
                    audioSource.PlayOneShot(soundMeelePlayer);
                }
            }
        }
        public class Bullet : MonoBehaviour
        {
            public Rigidbody2D rb2d;
            public Vector2 direction;
            public int speed;
            public float timer;
            public float MaxTimer;

            void Start()
            {
                rb2d = GetComponent();
            }

            void Update()
            {
                Move();
            }

            void Move()
            {
                rb2d.velocity = direction * speed;
                timer += Time.deltaTime;
                if (timer >= MaxTimer)
                {
                    Destroy(gameObject);
                    timer = 0;
                }
            }
        }
