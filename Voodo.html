Acerca del Proyecto

"Voodoo" es un videojuego de plataformas 3D con temática de puzzles, en el que participé como programador dentro de un equipo de 9 integrantes. El proyecto representó un reto importante, ya que fue el primer videojuego en 3D en el que trabajé, debido a su mayor escala de desarrollo.

El juego sigue la historia de un personaje convertido en un muñeco vudú por un brujo, quien debe escapar de una casa llena de obstáculos y desafíos mientras explora un entorno que parece gigantesco debido a su reducido tamaño.

El videojuego cuenta con 2 niveles y una Boss Fight, cada uno diseñado para ofrecer una experiencia diferente al jugador.

Lo que realicé

En este proyecto participé como programador de gameplay en Unity, desarrollando mecánicas del jugador, comportamiento de enemigos, sistemas interactivos y UI.         using System.Collections;
        using System.Collections.Generic;
        using UnityEngine;
        using UnityEngine.SceneManagement; 

        public class Villager : MonoBehaviour
        {
            public int ammo;
            public GameObject bulletPrefab;
            public GameObject bulletPrefab2;
            public float direction;
            public BulletManager bulletManager;
            public AudioSource audioSource;
            public AudioClip soundShootPlayer;
            public AudioClip AmmoClip;


            void Update()
            {
                Shoot();
                Move();
            }

            void Move()
            {
                //Movimiento y direccion
                float horizontal = Input.GetAxis("Horizontal");
                if (horizontal > 0)
                {
                   direction = 1;
                }
                else if (horizontal < 0)
                {
                   direction = -1;
                }

                Vector3 scale = transform.localScale;
                if (direction < 0)
                {
                   scale.x = -2;
                }
                else
                {
                   scale.x = 2;
                }
                transform.localScale = scale;

                rb2d.velocity = new Vector2(horizontal * speed, rb2d.velocity.y);
                animator.SetFloat("speed", rb2d.velocity.x);

            }

            void Shoot()
            {
                //Ataque a distancia
                //Apreta la tecla "X" para poder disparar
                if (Input.GetKeyDown(KeyCode.X) && ammo >= 1 && Time.timeScale > 0)
                {
                    GameObject obj = Instantiate(bulletPrefab);
                    obj.transform.position = transform.position;
                    Vector2 dir = obj.GetComponent().direction;
                    dir.x = direction;
                    obj.GetComponent().direction = dir;   
                    ammo--;
                    bulletManager.SetBullet(ammo);
                    audioSource.PlayOneShot(soundShootPlayer);
                } 
               
            }

            private void OnTriggerEnter2D(Collider2D collision)
            {
                //Recoges la municion de tus balas para poder disparar
                if (collision.gameObject.CompareTag("Ammo"))
                {
                    ammo++;
                    bulletManager.SetBullet(ammo);
                    Destroy(collision.gameObject);
                    audioSource.PlayOneShot(AmmoClip);
                }

            }

        }




       
        using System.Collections;
        using System.Collections.Generic;
        using UnityEngine;

        public class Bullet : MonoBehaviour
        {
            public Rigidbody2D rb2d;
            public Vector2 direction;
            public int speed;
            public float timer;
            public float MaxTimer=1f;

            void Start()
            {
                rb2d = GetComponent<Rigidbody2D>();
            }

            void Update()
            {
                Move();
            }

            void Move()
            {
                //Movimiento y vida de tiempo de la bala
                rb2d.velocity = direction * speed;
                timer += Time.deltaTime;
                if (timer >= MaxTimer)
                {
                    Destroy(gameObject);
                    timer = 0;
                }
            }
        }

Lo que aprendi

Este proyecto representó mi primera experiencia desarrollando un videojuego en Unity, por lo que aprendí muchos conceptos relacionados con la programación y el uso del motor de Unity. Al inicio pensé que sería una tarea complicada, ya que trabajábamos en un equipo de 4 integrantes donde cada uno tenía un rol más definido. En mi caso, al comienzo no tenía una especialidad marcada, pero debido a la falta de programadores en el grupo asumí la responsabilidad de encargarme de la programación.

Con el paso del desarrollo, fui adaptándome cada vez más a ese rol y descubrí que la programación era un área que realmente me interesaba. A medida que avanzaba el proyecto, comprendí mejor como resolver problemas y aplicar lógica de programación dentro de Unity. Gracias a esta experiencia, mejoré mis habilidades técnicas y gané más confianza trabajando en proyectos de desarrollo de videojuegos.
